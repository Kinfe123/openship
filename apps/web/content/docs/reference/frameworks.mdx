---
title: Supported stacks
description: Every framework, language, and runtime Openship detects automatically, with the `framework` value to use in openship.json when you want to pin one.
---

Openship looks at your repo when you import it and picks a stack automatically. It checks
package dependencies and well-known config files, then fills in the build command, start command,
port, and output directory for you in the [deploy wizard](/docs/guides/deploy-from-github).

If detection picks the wrong stack, or you want to pin it, set `framework` in
[`openship.json`](/docs/reference/openship-json) to one of the values below:

```json
{
  "$schema": "https://openship.io/openship.schema.json",
  "framework": "nextjs"
}
```

The tables list the main signals for each stack. Some stacks match more files than shown.
